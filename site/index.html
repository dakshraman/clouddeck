Deep Dive Architecture

Engineered for performance, not bloat.

A radical departure from 1990s legacy control panels. Explore the modern foundations powering CloudDeck under the hood.

Zero-Root Web Layer

The Next.js 15 panel runs as an unprivileged user (clouddeck). A privileged Go daemon listens strictly on 127.0.0.1:9090. No browser request ever executes shell strings (no sh -c).

Typed argument arrays only

<50 MB Idle Memory

cPanel consumes 1.5GB+ RAM just idling. CloudDeck runs effortlessly on a $3.50/mo 1-vCPU 1GB RAM cloud VPS, saving you hundreds of dollars in unnecessary infrastructure costs.

30x lighter than cPanel

Local Dev Suite (XAMPP Alt)

Turn Windows 10/11 (WSL 2) and macOS into a modern LEMP workstation with Nginx production parity, multi-PHP coexistence, and automated Root CA green padlocks on *.local.

Windows PATH & macOS brew

Web Terminal PTY

Full xterm.js terminal running directly inside your browser. Synchronized credentials allow instant elevation with sudo -i without leaving the dashboard.

PTY Unix socket streaming

PowerDNS Authoritative

Built-in SQLite-backed nameserver. Manage A, AAAA, CNAME, MX, TXT, SRV, and CAA records with 1-click automated publishing for mail and DKIM records.

Port 53 Native DNS

Zero 3rd-Party Go Dependencies

The Go agent daemon relies strictly on the Go standard library. No bloated dependency trees, zero supply chain attack vectors, and instant single-binary execution.

Static binary • stdlib only

Frequently Asked Questions

Got questions? We have answers.

Everything you need to know about switching to CloudDeck.

CloudDeck uses a compiled Go binary (stdlib only) for its system agent and a self-contained Next.js 15 server for the web panel. Unlike cPanel's 1990s legacy Perl/CGI monolith, CloudDeck does not run background interpreter daemons or duplicate services. It directly interfaces with native Linux binaries (Nginx, MariaDB, PowerDNS, Postfix) with zero virtualization overhead.
