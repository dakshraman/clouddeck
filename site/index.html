System Architecture

Engineered for performance, not legacy bloat

A departure from 1990s legacy control panels. Explore the foundations, bare-metal runtime engine, and security separation powering CloudDeck.

Zero-Root Web Layer

The Next.js 16 panel runs as an unprivileged user (clouddeck). The privileged Go daemon listens strictly on 127.0.0.1:9090. No browser request can ever execute shell strings.

Typed argument arrays only

Under 50MB Idle Memory

cPanel consumes 1.5GB+ RAM just idling. CloudDeck runs effortlessly on a standard 1-vCPU 1GB RAM cloud VPS, eliminating unnecessary hosting overhead.

Lightweight Go stdlib core

Local Workstation Suite

Turns Windows 10/11 (WSL 2) and macOS into an authentic LEMP workstation with Nginx production parity, multi-PHP coexistence, and automated Local Root CA padlocks on *.local.

Windows PATH / macOS brew

In-Browser Terminal (PTY)

Interactive xterm.js terminal connected directly to native system PTY sessions over authenticated WebSockets with elevation rights and audit tracking.

PTY streaming / xterm.js

Authoritative PowerDNS

Integrated SQLite-backed nameserver. Manage A, AAAA, CNAME, MX, TXT, and CAA records with automated publishing for mail, SPF, and DKIM.

Port 53 authoritative DNS

Zero 3rd-Party Go Dependencies

The Go agent daemon relies strictly on Go 1.23 standard library packages. No bloated dependency trees, zero supply chain attack vectors, and instant single-binary execution.

Static binary / stdlib only

Frequently Asked Questions

Questions and technical details

Everything you need to know about switching to CloudDeck and managing servers.

How can CloudDeck consume under 50MB RAM when cPanel uses 1.5GB+?

CloudDeck uses a compiled Go binary (stdlib only) for its system agent and an unprivileged Next.js server for the web panel. Unlike cPanel's legacy Perl/CGI monolith, CloudDeck does not run persistent interpreter daemons or duplicate services. It directly interfaces with native Linux binaries (Nginx, MariaDB, PowerDNS, Postfix) with zero virtualization overhead.

How does the Zero-Root security model protect my server?

The web panel runs as an unprivileged system user ('clouddeck'). It never executes root commands directly. Instead, it sends token-authenticated typed requests over 127.0.0.1:9090 to the privileged Go daemon. The agent executes external commands using explicit, typed argument arrays with strictly validated regex patterns. Shell string interpolation ('sh -c') is impossible.

Can I replace XAMPP / WAMP / MAMP on my Windows or Mac workstation?

Yes. CloudDeck's Local Development Suite installs cleanly on Windows 10/11 (via WSL 2) and macOS (via Homebrew). You get true Nginx production parity, multi-PHP (8.1–8.4) socket switching, deep-linked phpMyAdmin, and automated Local Root CA green padlocks on https://*.local without Apache rewrite quirks.

How does multi-PHP coexistence work without Docker?

CloudDeck provisions separate PHP-FPM pools for each supported PHP version (8.1, 8.2, 8.3, 8.4) listening on dedicated Unix domain sockets (/run/php/php8.x-fpm.sock). When you select a PHP version in a site's settings, CloudDeck renders the Nginx fastcgi_pass directive to point directly to that socket, achieving zero-overhead native execution.

What developer AI tooling is integrated into CloudDeck?

CloudDeck integrates orchestrators for Claude Code, OpenAI Codex, Antigravity, OpenCode, Aider, Ollama, Goose, and Hermes Agent. You can inspect installation states, launch them directly in the browser terminal, and store credentials safely in an encrypted mode-0600 key vault that automatically exports keys to shell sessions.

How do Dual-Mode .zip backups protect my data?

CloudDeck creates standard, cross-platform .zip archives containing your site document root and MariaDB database dump. You can download the archive to your personal computer for off-site cold storage or retain it on the server for 1-click in-place restoration, with optional automated sync to Telegram or cloud storage.

How does CloudDeck manage cron jobs and scheduled tasks?

CloudDeck includes a visual Cron Job Manager. You can schedule tasks using human-readable presets (Every Minute, Hourly, Daily, Weekly, Monthly) or standard 5-field crontab syntax. It features 1-click 'Run Now' testing to verify scripts before scheduling, real-time stdout/stderr log capture, and active/inactive toggles.

Is CloudDeck truly 100% free and open-source?

Yes. CloudDeck is free and open-source software under the MIT license. There are no monthly per-server fees ($30–$60+/month like cPanel), no per-domain caps, and no paywalled 'Pro' or 'Enterprise' feature restrictions.

What Linux distributions are supported in production?

Ubuntu (20.04, 22.04, 24.04 LTS) and Debian (11, 12) on both x86_64 and arm64 architectures are fully automated by the installer. Any systemd-based Linux distribution can run CloudDeck using the static Go agent binary.
