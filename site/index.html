Security model

The web app never runs as root.

Most control panels put a root process behind a web login. CloudDeck splits the architecture in two: an unprivileged Next.js panel for the browser, and a small privileged Go agent that strictly accepts token-authenticated, typed operations over localhost.

Least privilege by design

The Next.js panel runs under the unprivileged clouddeck user. Only the Go agent runs as root, bound strictly to 127.0.0.1:9090 and protected by an auth token.

Typed commands, no shell

Every external command runs through an explicit argument array. Callers cannot inject shell strings — there is no sh -c injection vulnerability.

Permanent audit logging

Every mutating action is permanently appended to a JSONL audit log with timestamp, action, params, and outcome. Tasks keep live logs.

Path-confined file manager

Domains are validated before filesystem paths are derived. The file manager stays inside the site webroot and strictly rejects symlink escapes.

Why choose CloudDeck over cPanel?

cPanel costs $30–$60+/month per server ($360–$720+/yr) and consumes over 1.5GB of RAM running a legacy 1990s Perl monolith directly as root. CloudDeck is 100% free and open-source, runs on under 50MB of idle RAM, uses Next.js 15 + Go, and never exposes a root process behind a browser login.

How is CloudDeck safer than aaPanel or CyberPanel?

aaPanel and CyberPanel run their entire Python web app directly as root, creating a history of critical remote code execution (RCE) vulnerabilities. CloudDeck enforces strict privilege separation: the browser only reaches an unprivileged Next.js UI, which proxies typed JSON requests to a local Go daemon using explicit argument arrays — preventing sh -c shell injections completely.

Can I host Node.js, Python, Go, and Ruby applications?

Yes! CloudDeck includes first-class application hosting with automatic port assignment, systemd process supervision, live log streaming, and automatic Nginx reverse proxy configuration. You can mount apps at the site root or at subpaths.

What Linux distributions are supported?

The one-command installer fully provisions Debian and Ubuntu servers, including Nginx, PHP-FPM, MariaDB, certbot, PowerDNS, and Node.js. On other Linux distributions (Fedora, Arch, AlmaLinux), the installer installs the panel and agent, and you bring your host web stack.

How does 1-Click Panel SSL work?

With v0.6.25, CloudDeck allows you to enable Panel SSL with a single click. It supports Self-Signed certificates with IP SANs (so browsing directly to https://<your-ip>:2083 is valid) or Let's Encrypt for domains. The agent configures an automated Nginx reverse proxy that forwards port 2083 to the internal panel listener with HTTP-to-HTTPS redirection.

How do upgrades work?

Run sudo clouddeck update to seamlessly upgrade to the latest release, or upgrade with one click directly inside the panel Settings page. All databases, site files, and configurations remain untouched.
