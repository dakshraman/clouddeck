Security model

The web app never runs as root.

Most control panels put a root process behind a web login. CloudDeck splits the architecture in two: an unprivileged Next.js panel for the browser, and a small privileged Go agent that strictly accepts token-authenticated, typed operations over localhost.

Least privilege by design

The Next.js panel runs under the unprivileged clouddeck user. Only the Go agent runs as root, bound strictly to 127.0.0.1:9090 and protected by an auth token.

Typed commands, no shell

Every external command runs through an explicit argument array. Callers cannot inject shell strings — there is no sh -c injection vulnerability.

Permanent audit logging

Every mutating action is permanently appended to a JSONL audit log with timestamp, action, params, and outcome. Tasks keep live logs.

Path-confined file manager

Domains are validated before filesystem paths are derived. The file manager stays inside the site webroot and strictly rejects symlink escapes.

Frequently Asked Questions

Does CloudDeck work offline or locally without internet?

Yes. When installed on Windows (WSL 2) or macOS via the Local Development Suite, CloudDeck runs completely offline on localhost:2083. Your local sites, multi-PHP runtimes, MariaDB databases, and local SSL certificates operate without an active internet connection.

What are the minimum server specs for Linux VPS?

CloudDeck is ultra-lightweight and consumes under 50MB of RAM idle. It runs comfortably on a $3.50/mo 1 vCPU, 1GB RAM VPS (Ubuntu 22.04/24.04 or Debian 11/12). The installer automatically provisions a 1GB swapfile on systems with <2GB RAM to ensure build reliability.

How does CloudDeck replace XAMPP, WAMP, and MAMP for local development?

Unlike XAMPP/WAMP which use legacy Win32 Apache binaries prone to .htaccess rewrite bugs, CloudDeck provides 100% production parity with high-performance Nginx, 1-click multi-PHP switching (8.1, 8.2, 8.3, 8.4), isolated phpMyAdmin, and automatic Local Root CA green padlocks on Windows and macOS.

How do the new Dual-Mode .zip Backups work?

CloudDeck packages both entire websites and MariaDB databases as standard .zip files. You can download archives directly to your personal computer for off-site cold storage (and restore anytime via the drag-and-drop dropzone) or keep them safely stored on the server for instant 1-click restoration.

Is CloudDeck completely free? Are there any hidden fees or paywalled features?

CloudDeck is 100% free and open-source under the MIT license ($0/month). There are zero per-site limits, zero artificial tiers, and zero paywalled features. You can host unlimited websites, databases, and mail domains across as many servers as you like.

Why is CloudDeck safer than aaPanel or CyberPanel?

Panels like aaPanel and CyberPanel run their entire Python/PHP web layer directly as root, which has led to critical remote code execution (RCE) vulnerabilities. CloudDeck runs its Next.js 15 UI as an unprivileged user, communicating over loopback with a privileged Go daemon using strict, typed exec arrays without shell invocation (no sh -c).

Can I manage Node.js, Python, and Go apps alongside PHP?

Yes. CloudDeck includes polyglot application hosting. You can deploy Node.js, Python, Go, and Ruby applications with automatic port assignment, systemd supervision, reverse proxying through Nginx, and live log streaming from the dashboard.
