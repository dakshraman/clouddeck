SYSTEM ARCHITECTURE • v0.6.53

Engineered for performance, not bloat.

A radical departure from 1990s legacy control panels. Explore the modern foundations, autonomous AI agents, and bare-metal runtime engine powering CloudDeck.

Zero-Root Web Layer

The Next.js 16 panel runs as an unprivileged user (clouddeck). A privileged Go daemon listens strictly on 127.0.0.1:9090. No browser request ever executes shell strings (no sh -c).

Typed argument arrays only

<50 MB Idle Memory

cPanel consumes 1.5GB+ RAM just idling. CloudDeck runs effortlessly on a $3.50/mo 1-vCPU 1GB RAM cloud VPS, saving you hundreds of dollars in unnecessary infrastructure costs.

Local Dev Suite (XAMPP Alt)

Turn Windows 10/11 (WSL 2) and macOS into a modern LEMP workstation with Nginx production parity, multi-PHP coexistence, and automated Root CA green padlocks on *.local.

Windows PATH • macOS brew

Web Terminal PTY

FREQUENTLY ASKED QUESTIONS

Got questions? We have answers.

Everything you need to know about switching to CloudDeck and utilizing AI agents.

CloudDeck uses a compiled Go binary (stdlib only) for its system agent and a self-contained Next.js 16 server for the web panel. Unlike cPanel's legacy Perl/CGI monolith, CloudDeck does not run persistent interpreter daemons or duplicate services. It directly interfaces with native Linux binaries (Nginx, MariaDB, PowerDNS, Postfix) with zero virtualization overhead.
